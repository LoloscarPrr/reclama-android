# Reclama

**Tus derechos, sin la burocracia.**

Aplicación Android para convertir problemas de consumo en casos estructurados, accionables y fáciles de seguir.

## Estado

`v0.1.0-alpha — Foundation` en desarrollo.

## Stack

- Kotlin
- Jetpack Compose
- Clean Architecture + MVVM (arquitectura objetivo)
- Android API 26+
- GitHub Actions

## Principios

- La IA interpreta y redacta; no inventa reglas jurídicas.
- Derechos, rutas y plazos se resuelven mediante componentes deterministas.
- El usuario conserva control sobre cualquier acción externa.
- Privacidad por diseño.
